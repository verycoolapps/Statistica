## ⬇️ Download & Install

### Windows

```
1. Go to Releases → Download statistica-win32.zip
2. Extract to any folder
3. Double-click Statistica.exe
4. Done. No installer. No setup. No internet.
```

### macOS

```
1. Go to Releases → Download Statistica.dmg (or statistica-mac.zip)
2. Open DMG → drag to Applications
3. Right-click → Open (first time, to bypass Gatekeeper)
4. Done.
```

### Linux

```bash
# Download statistica-linux.tar.gz from Releases, then:
tar xzf statistica-linux.tar.gz
cd Statistica-linux-x64
./Statistica
```

### Build from Source / Dari Source Code

```bash
# Clone the repo
git clone https://github.com/verycoolapps/Statistica.git
cd Statistica

# Install dependencies
npm install

# Run in development
npm start

# Build for your platform
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

**Requirements / Persyaratan:**
- Node.js 20+
- npm 10+

## 🏗️ Arsitektur / Architecture

```
src/
├── main.js              ← Electron main process (IPC, file dialogs)
├── preload.js           ← Secure context bridge
└── renderer/
    ├── index.html       ← App shell (sidebar + content area)
    ├── css/
    │   └── style.css    ← Dark theme + full UI system
    └── js/
        ├── i18n.js      ← Bilingual strings (ID + EN) — 500+ keys
        ├── stats.js     ← Statistical engine (jStat + pure JS math)
        ├── charts.js    ← Chart rendering (Chart.js 4 + Plotly)
        └── app.js       ← UI orchestrator + analysis router
```

### Stack

| Layer | Technology |
|---|---|
| Runtime | Electron 42 |
| Stats Engine | jStat 1.9, Pure JS |
| Charts | Chart.js 4.5, Plotly 3.5 |
| CSV Parsing | PapaParse 5.5 |
| File I/O | Electron dialog + Node.js fs |
| i18n | Custom key-path resolver |
| Security | contextIsolation: true, nodeIntegration: false |

---

## 🔒 Security / Keamanan

- ✅ `contextIsolation: true` — renderer tidak bisa akses Node.js API langsung
- ✅ `nodeIntegration: false` — zero Node.js exposure di renderer
- ✅ Preload script sebagai satu-satunya bridge
- ✅ Semua file I/O melalui IPC handler yang terkontrol
- ✅ 100% offline — tidak ada data yang keluar dari perangkat kamu
- ✅ Tidak ada telemetri. Tidak ada analytics. Tidak ada akun. Privasi total.
